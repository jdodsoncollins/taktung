# Product direction

Taktung is a local-first Vercel operations assistant. Native SwiftUI, built with Xcode 27.1 for iOS 27.0+.

The same size-driven workspace serves conventional iPhones, the Duo outer/inner continuum, and iPad windows. Product state belongs above adaptive layout branches. Native bars retain their system placement; the selected-site title remains visible.

Visual review and device history add durable evidence to the operations workflow. Compare renders the selected deployment and a READY reference in fresh anonymous WebKit sessions, with an optional accepted baseline saved per project/path. Activity stores checks, confirmed action results, comparison events, and user notes per Vercel account/team. Search and export operate on that local journal. These records describe work performed on this device, rather than a complete Vercel audit log. See [visual comparison and history](visual-comparison-and-history.md).

Same product rules as the Expo Takt app:

- Selected site is the header title.
- No N+1 deployment list from Home or the site picker.
- Env **values** never appear.
- Mutators: allow-list, ConfirmationPolicy, hard confirm, READY only after poll.
- Demo fixtures are screenshot-only and never mix with a live token.
